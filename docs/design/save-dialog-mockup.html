Save a link

Save in the top bar opens the form over the page you're on, instead of sending you to a separate plain page. Both options use the site's fields, buttons, busy look and Undo bar. Pick a state to see it. Each Replay runs the open and save motion.

A · Dialog (recommended)

This is the same family as the edit dialog you already use. On a computer it's a card in the middle that dims the page. On a phone it's a sheet that slides up from the bottom, with Cancel and Save along the top where your thumb is. Saving is a short task you finish and leave, so it gets the whole screen's attention, then gets out of the way.

What changes, either way

  • Opening. Save in the top bar (and in the phone menu) opens the form over the page, with the cursor already in Address. Escape, Cancel or a click on the dimmed page closes it. Anything you typed is kept until you save.
  • Address. As you type or paste, a small square at the start of the field shows the site's first letter, and the line below says where it's from, so a mistyped address shows before you save. An address that isn't a web address is pointed out under the field when you press Save. Your words stay where they were.
  • Saving. Nothing changes for the first 300ms, so a quick save never flickers. After that, the form dims and the button says Saving…, the same busy look as every other button on the site.
  • Saved. The button shows a tick for a moment, the dialog closes, and the Undo bar says Saved "Title". Undo deletes the link you just saved. The Undo bar announces successes everywhere else on the site, so this stays consistent.
  • Already saved. The dialog stays open and shows the link you already have: when you saved it, why, and Open it. If it was done or put away, it also offers Bring it back. If your new reason wasn't used because the link already had one, it says so.
  • Errors. These show in the dialog's message box above the buttons, in plain words. Everything you typed stays, so Save can simply be pressed again. Error text is never amber, since amber means "needs you".
  • The bookmarklet still opens the page at /save, because it starts from another site in a new tab. That page gets the same form in a card under the usual top bar, instead of the bare page in the screenshot.
  • Motion only answers what you did: the dialog fades and grows slightly as it opens (the sheet slides up on a phone), the tick appears, and the Undo bar slides in. With reduced motion turned on, all of it is instant.
