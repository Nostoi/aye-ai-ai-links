# Tables in saved copies: implementation plan

> **For agentic workers:** use superpowers:subagent-driven-development or superpowers:executing-plans. Steps use checkbox syntax.

**Goal:** a saved copy of a page with a data table shows a table, not a column of loose words. New copies write GFM tables, and the copy page renders them. One PR. It is step 2 of #223's landing sequence.

## Grounding

What it enables, reachable today: any article with a `<table>` (a price list, a spec sheet, a comparison). On main 2115395, `articleMarkdown` given `<table><tr><th>Name</th><th>Age</th></tr><tr><td>Ann</td><td>3</td></tr></table>` writes `Name\n\nAge\n\nAnn\n\n3`: each cell its own paragraph (scratch run, Turndown 7.2.4 with linkedom 0.18.13). Turndown's core has no table rule, as the saved-copy spec says ("a table comes out as its text"), and `copy-markdown.ts` builds markdown-it from the `commonmark` preset, which has no `table` rule.

- OBSERVED: owner ruling on #223 (2026-10-21): "add table support… only copies made from now on get tables". The ruling named Turndown's GFM plugin as the way.
- OBSERVED (scratch run): neither GFM plugin works on our DOM. `@joplin/turndown-plugin-gfm` 1.0.68 and `@truto/turndown-plugin-gfm` 1.0.5 both read `table.rows`, which linkedom 0.18.13 doesn't implement (`rows` is `undefined`). With them, a two-by-two table came out as `NameAgeAnn3` (Joplin) or as nothing at all (Truto, whose skip check drops the table's content).
- OBSERVED (source read): Joplin's fallback for a cell holding blocks writes the table as raw HTML, which `copy-markdown.ts` (`html: false`) would show as literal tags. Truto escapes `|` to `\|` and then doubles every backslash, which gives `\\|`, and that ends the cell early.
- OBSERVED: linkedom puts a `<tr>` written straight under `<table>` directly under it, with no `<tbody>`. `Element.closest` works. Readability 0.6 keeps tables in the article, including nested layout tables (scratch run).
- OBSERVED: markdown-it 15.0.2 with `table` enabled renders `\|` inside a link address or a code span in a cell as a literal `|`. A column with alignment (`:-:`) gets a `style="text-align:…"` attribute. A table can interrupt a paragraph. On 2 MB of rows it took about 1.6 s, on 2.7 MB of 30,000 columns about 2.4 s, and on 2 MB of pipes 85 ms (scratch run). A copy's Markdown is capped at `MAX_COPY_MARKDOWN_BYTES` (2 MiB).
- OBSERVED: a copy's Markdown is rendered in one place, `copyHtml` (`src/web/copy-markdown.ts`). The export writes it byte for byte. Copies are write-once (saved-copy spec §12).
- OBSERVED: the copy page carries no `style=` attribute; its one style is `PAGE_STYLE`, hashed into `COPY_HEADERS` (`src/web/AGENTS.md`).

## Decisions

- **Our own Turndown rules, no new dependency.** This changes how, not what, the owner ruled: the plugins fail on linkedom, and patching `rows` onto linkedom's elements would still leave Joplin's raw-HTML fallback. The rules live in a new `src/fetch/copy-tables.ts`, and `articleMarkdown` adds them.
- **Which tables become Markdown tables.** A table is written as a grid only when all of these hold. Any other table keeps today's output (its text, block by block), so nothing is lost or misaligned:
  - it holds no other table (a layout table);
  - it has at least two rows and at least two columns;
  - no cell has `rowspan` over 1, since Markdown can't keep rows aligned around one;
  - no cell holds a heading, list, `pre`, quote, rule or definition list.
  A table inside a layout table can still be a grid.
- **The shape.** The table's first row, in document order, is the header row, whether its cells are `th` or `td`. A delimiter row of `---` follows, with no alignment. Every row has the table's column count: a cell with `colspan` n is followed by n − 1 empty cells, and a short row is padded with empty cells at the end. A cell's content is Turndown's conversion of it (links and pictures as usual), with every run of whitespace, line breaks included, turned into one space and each `|` written `\|`. A `caption` becomes a paragraph just before the table.
- **Rendering (`copy-markdown.ts`).** Enable markdown-it's `table` rule. A core rule removes the `style` attribute from `th_open` and `td_open`, so the page still carries no `style=`. `table_open` and `table_close` render inside `<div class="copy-table">` so a wide table scrolls sideways in its own box. `safeTokens` already walks every inline token, cells included.
- **Styles (`theme.ts`).** Enough to read the table: a scroll box, cell lines in `--line`, padding, left-aligned text. #223's step 3 restyles the whole reader.
- **Old copies.** A stored copy with a line like `| a | b |` followed by `| --- | --- |` would now render as a table. Turndown escapes a leading `-`, but not a leading `|`, so this needs those exact two lines in an article's text. Accepted.
